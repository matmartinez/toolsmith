# Toolsmith

A Swift CLI that bridges Model Context Protocol transports — a port of [`sparfenyuk/mcp-proxy`](https://github.com/sparfenyuk/mcp-proxy). Wraps stdio MCP servers behind SSE/StreamableHTTP, and vice versa.

## Build

```sh
swift build
```

## Run

```sh
swift run toolsmith --help
```

## Test

```sh
swift test
```
